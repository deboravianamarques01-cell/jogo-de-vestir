# 👗 Jogo de Vestir Neurodivergente

Um jogo de vestir inclusivo e acessível, desenvolvido com foco em necessidades neurodivergentes.

## 🎮 Sobre o Projeto

Este é um jogo interativo de vestir pensado para ser:
- **Acessível** - Interface clara e intuitiva
- **Inclusivo** - Desenhado com consciência neurodivergente
- **Divertido** - Múltiplas opções de personalização
- **Responsivo** - Funciona em diferentes dispositivos

## ✨ Funcionalidades

- Seleção de roupas e acessórios
- Combinações de cores personalizáveis
- Interface simplificada e amigável
- Sem pressão de tempo ou pontuação
- Temas e paletas de cores adaptáveis

## 🚀 Como Usar

1. Abra o arquivo `index.html` em seu navegador
2. Escolha as roupas e acessórios que quiser
3. Personalize as cores conforme sua preferência
4. Divirta-se criando looks!

## 📁 Estrutura do Projeto

```
jogo-de-vestir/
├── index.html       # Página principal
├── style.css        # Estilos e design
├── script.js        # Lógica do jogo
├── assets/          # Imagens e recursos
│   ├── clothes/
│   ├── accessories/
│   └── backgrounds/
└── README.md        # Este arquivo
```

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla)

## 💡 Inspirações Neurodivergentes

Este projeto incorpora boas práticas para:
- Redução de estímulos visuais conflitantes
- Navegação clara e consistente
- Sem elementos que piscam ou se movem rapidamente
- Paletas de cores neutras e relaxantes disponíveis
- Sem contadores de tempo ou pressão de performance
